# DeepChest-Medical-System-
end - to - end ai medical system for diagnosing and classifying chest diseases using ensemble learning and transfer learning 
this system has 3 ai models : densent121 , efficientnet-b0 , convnext-tiny 
the voting (diagnosis / classifying) mechanism is dynamic , weighted-sum hard voting way  
the project has both front-end and back-end
front-end : basic html , css , js with futuristic ui / ux design and animations 
back-end : fastapi with encryption for both tabular and image data
